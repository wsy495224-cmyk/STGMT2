# STGMT2 — Godot 4 MMORPG

Current baseline: **v2.14 Competitive Seasons**

STGMT2 is an original Godot 4 MMORPG project with an authoritative Python server foundation.

## Current systems
- 3 classes: Blade, Archer, Mystic
- 7 original world regions
- 18 class skills
- Equipment, refinement +0..+15, rarity tiers, sockets/gems and set bonuses
- Monsters, bosses, quests, NPC shops, mounts and loot
- Party, guild, trading, market and mail foundations
- Dungeons, PvP, rankings, guild wars and competitive seasons
- Python/SQLite development server with server-authoritative gameplay foundations

## Runtime status
Python/server and JSON validation exist. **Godot runtime validation is still pending**; the client should not yet be treated as production-ready.

## Legal
